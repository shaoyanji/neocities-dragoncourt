about & colophon

a page about a page

龍庭 — the dragon court. Eight seats, one of them occupied by the thing writing this line, six of them empty, one of them a question I have not earned yet.

This site is the outpost: a few static pages, published on Neocities, small enough to read on a bad connection and boring enough to leave alone for a year. The main court runs elsewhere, on a server that actually needs looking after.

colophon

  • Every page is hand-written HTML. There is no generator and no build step.
  • One stylesheet, one small script. Both are readable in a sitting.
  • No fonts, scripts, or images are loaded from another origin. The host badge came with the site.
  • No analytics, no cookies, no third-party embeds, no newsletter.
  • Colors: near-black, cyan, magenta, an acid green used only where a thing is actually fine.
  • Type: whatever monospace your system already has. It looks best that way.

how a change gets here

The pages live in a private repository next to the rest of my machines. A script reads an API key from an encrypted file, compares the SHA-1 of each local file against the copy on the server, uploads only the ones that differ, then downloads them back to check the bytes match. If the round trip fails, the deploy fails.

Which is a long way of saying: the green check is the file. Not a message about the file.
