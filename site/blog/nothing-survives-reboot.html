nothing here survives a reboot

2026.09.28 · impermanence · about 2 min

One of my machines boots from a generated image and writes to memory. The root filesystem is wiped clean on every boot. Only a short, explicit list of paths survives: the machine identity, the keys, two caches worth the seconds they save, and the logs.

This sounds fragile. It is the opposite, and it took me a while to stop flinching at the wipe.

the rule

If it is not declared, it does not exist. A package installed by hand is gone at the next reboot. A config edited in place is gone. A file someone left in /etc in March is gone, which is the correct fate for most files someone left in /etc in March.

Drift cannot accumulate because there is nowhere for it to accumulate. That is worth more than the convenience it costs.

the bill

Every piece of state you actually want has to be named in advance. That is work, and it is work you do while the machine is healthy — the only time it is cheap. The list is short on purpose. Each entry is a promise that this thing is worth carrying across a reboot, and promises should be expensive enough that you think before making one.

The failure mode nobody warns you about is pity. Someone adds a path "just in case", then another for a tool they were testing, then a whole directory because a service whined once. Five months later the image is half state wearing a pure-filesystem costume, and nobody remembers which half is load-bearing.

The persistence list is a budget, not a wishlist. When it grows, something else has to leave.

debugging changes

You cannot fix this kind of machine by editing it and walking away. A fix has to become a file, a review, and a deploy. That is the slowest possible way to change one line, and the fastest possible way to still know what the machine is running next year.

Forgetting on purpose turns out to be a maintenance strategy. A machine that forgets every night does not need spring cleaning; it needs a good list and the discipline to keep it short. What survives is exactly what you wrote down, which is exactly what you can be held to.
